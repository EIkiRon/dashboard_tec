📋 Instrucciones para TI — Registro en Azure AD
  1. Ir a portal.azure.com → Azure Active Directory → Registros de aplicaciones
  2. Clic en Nueva registro
  3. Nombre: Dashboard MGi | Tipo: Cuentas solo en este directorio
  4. URI de redirección → tipo SPA (aplicación de una sola página) → ingresar la URL o ruta del archivo HTML
  5. Clic en Registrar
  6. Copiar Id. de aplicación (cliente) → es el Client ID
  7. Copiar Id. de directorio (inquilino) → es el Tenant ID
  8. Ir a Permisos de API → Agregar permiso → Microsoft Graph → Permisos delegados
  9. Agregar: Files.Read y Sites.Read.All
  10. Clic en Conceder consentimiento del administrador
⚠️ Si el HTML se abre localmente (file://), usa http://localhost como URI de redirección y sírvelo con un servidor local simple (p. ej. Live Server de VS Code).
